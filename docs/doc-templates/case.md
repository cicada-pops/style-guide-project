# Шаблон описания дела

Описание дела читает игрок.
Ему должно быть интересно читать сюжет и понятно, что именно нужно найти.

Описание дела хранится в классе дела в каталоге `backend/core/services/case_loader/cases/`.
Тексты из шаблона попадают в поля `title`, `short_description` и `description`.

## Структура

| Часть | Поле класса | Что написать |
| --- | --- | --- |
| Название | `title` | 1–3 слова, без слова «дело»: «Серебряный Ключ» |
| Анонс | `short_description` | 1–2 предложения для карточки дела, без спойлеров |
| Сюжет | `description` | Не больше 5 предложений: что случилось, где и когда |
| Задание | `description` | Что найти и по каким признакам |
| Формат ответа | `description` | Какое поле какой таблицы отправить |
| Доступные таблицы | `available_tables` | Только таблицы, нужные для решения |
| Требуемый опыт и награда | `required_xp`, `reward_xp` | Числа XP |

## Шаблон

```text
<Год>. <Что случилось — 1–2 предложения.>
<Детали, которые помогут найти преступника, — до 3 предложений.>

Задание: найдите человека, который:
- <признак 1>;
- <признак 2>.

Преступник может не входить в число подозреваемых.
Ответ — значение поля id из таблицы person.
```

## Проверка перед публикацией

- Сюжет не раскрывает ответ.
- Каждый признак из задания можно проверить SQL-запросом к доступным таблицам.
- У задания ровно один правильный ответ.
- Формат ответа указан явно.
