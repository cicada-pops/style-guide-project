# Шаблон README

README — первое, что видит разработчик в репозитории.
Он отвечает на три вопроса: что это, как запустить и где читать дальше.

README показывается на GitHub, поэтому примечания в нём оформляются по синтаксису GitHub (правило [MD-1](../rules/markdown.md#md-1-учитывайте-где-будет-показан-документ)).

## Структура

| Раздел | Что написать | Обязательный |
| --- | --- | --- |
| Заголовок и описание | Название и 1–2 предложения: что это и для кого | Да |
| Возможности | 3–6 пунктов о главном | Нет |
| Требования | Таблица инструментов с версиями | Да |
| Быстрый старт | Нумерованные шаги от клонирования до работающего приложения | Да |
| Команды для разработки | Таблица команд make | Да для сервисов |
| Документация | Ссылки на подробные документы | Нет |
| Лицензия | Название лицензии и ссылка на файл | Да |
