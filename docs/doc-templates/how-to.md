# Шаблон инструкции

Инструкция помогает выполнить одну конкретную задачу: запустить проект, добавить дело, сбросить базу.
Если задач несколько, напишите несколько инструкций.

## Структура

| Раздел | Что написать |
| --- | --- |
| Заголовок | «Как» + задача: «Как добавить новое дело» |
| Вступление | 1–2 предложения: что получит читатель |
| Перед началом | Что должно быть готово до первого шага |
| Шаги | Нумерованный список, одно действие в шаге |
| Как проверить результат | Как убедиться, что всё получилось |
| Если что-то пошло не так | Таблица «Проблема — Решение» |
| Что дальше | Ссылки на связанные инструкции |

## Шаблон

```markdown
# Как <сделать задачу>

<Что получит читатель после выполнения инструкции.>

## Перед началом

- <Что должно быть установлено или настроено.>

## Шаги

1. <Цель шага, если нужна>: <действие>.
2. <Действие.> <Результат действия.>

## Как проверить результат

<Что должен увидеть читатель.>

## Если что-то пошло не так

| Проблема | Решение |
| --- | --- |
| <Что видит читатель> | <Что сделать> |

## Что дальше

- [<Название связанной инструкции>](<путь>)
```
