# Словарь и глоссарий

Глоссарий объясняет термины предметной области SQL Hunt.
Словарь написания фиксирует, как писать названия технологий и заимствованные слова.

## Глоссарий

| Термин | Значение | В коде |
| --- | --- | --- |
| Дело | Детективная задача, которую решает игрок: сюжет, материалы и задание | `Case` |
| Материалы дела | Таблицы базы, доступные игроку в конкретном деле | `AvailableTable` |
| Схема дела | Список таблиц и полей, которые игрок видит в редакторе запросов | `schema` |
| Человек | Любое лицо в базе дела: подозреваемый, свидетель или посторонний | `Person`, таблица `person` |
| Подозреваемый | Человек, которого следствие связывает с делом. Настоящий преступник может не быть подозреваемым | `Suspect`, таблица `suspect` |
| Улика | Доказательство, найденное на месте преступления | `Evidence`, таблица `evidence` |
| Алиби | Объяснение подозреваемого, где он был во время преступления, и статус проверки | `Alibi`, таблица `alibi` |
| Показания | Заявление человека по делу | `Statement`, таблица `statement` |
| Место преступления | Адрес и дата преступления | `CrimeScene`, таблица `crime_scene` |
| Запрос | SQL-запрос, который игрок выполняет в редакторе. Разрешены только запросы `SELECT` | `sql` |
| Ответ | Значение, которое игрок отправляет как решение дела | `answer` |
| Опыт (XP) | Очки, которые игрок получает за раскрытое дело. Открывают доступ к новым делам | `xp`, `reward_xp`, `required_xp` |
| Прогресс | Статус дела для игрока: «не начато», «в процессе» или «завершено» | `UserProgress` |
| Задача | Фоновое выполнение запроса игрока в Celery | `task_id` |
