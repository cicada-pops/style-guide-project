# Руководство по стилю документации SQL Hunt

Правила написания и оформления документации для [SQL Hunt](https://github.com/cicada-pops/SQLHunt) — веб-игры, в которой игрок расследует дела с помощью SQL-запросов.

Руководство опубликовано на сайте [cicada-pops.github.io/style-guide-project](https://cicada-pops.github.io/style-guide-project/).

## Что внутри

| Каталог или файл | Содержимое |
| --- | --- |
| `docs/` | Страницы руководства в Markdown |
| `mkdocs.yml` | Настройки сайта и навигации MkDocs |
| `styles/SQLHunt/` | Правила Vale для проверки текста |
| `.markdownlint-cli2.yaml` | Правила markdownlint для проверки разметки |
| `.github/workflows/docs.yml` | Проверка, сборка и публикация сайта в GitHub Actions |

## Быстрый старт

1. Установите Python 3.9 или выше.
2. Создайте виртуальное окружение и установите зависимости:

    ```bash
    make install
    ```

3. Запустите сайт локально:

    ```bash
    make serve
    ```

4. Откройте `http://127.0.0.1:8000/style-guide-project/` в браузере.

## Команды

| Команда | Что делает |
| --- | --- |
| `make install` | Создаёт окружение `.venv` и устанавливает MkDocs |
| `make serve` | Запускает сайт локально с автообновлением |
| `make build` | Собирает сайт в каталог `site/` в строгом режиме |
| `make lint` | Запускает markdownlint и Vale |
